      📖 暮省使用指南

      🌙 这是什么？

      「暮省」是一个每日复盘工具，名字取自"暮而省"——晚间反省。睡前 5 分钟，记录今天的完成、学习、反思，规划明天。

      ✍️ 今日复盘

      默认页面，填写今天的：

      • 今日完成：自动带过来昨天的「明日计划」，完成的打勾 ✓
      • 心情：选一个 emoji
      • 亮点 / 困难 / 学习 / 反思：简单写几句
      • 效率评分 / 休息评分：点星星，1-5 颗

      填完点 💾 保存今日。

      ☀️ 明日计划

      写下明天最重要的 3 件事 + 其他待办 + 提醒。保存后，明天打开暮省时这些会自动出现在「今日完成」里。

      🧘 修行反思

      一条随机语录（道德经/庄子/禅宗）+ 三条修行提醒。写下今天的感悟、困惑、念头观察。可一键复制或导出。

      📅 历史记录

      所有日报按日期倒序排列，点击可展开详情。每条记录右边有：

      • 📊 周复盘：自动生成本周报告（趋势图 + 智能分析）
      • 📈 月复盘：自动生成本月报告
      • 🧠 AI 高我深读：AI 以"高我"视角深度分析你的数据

      🧠 AI 高我深读配置

      首次使用需要配置（仅一次）：

      • 点「⚡ 一键填充 DeepSeek 默认配置」
      • 输入 API Key（向分享者获取，或自己注册 platform.deepseek.com）
      • 点「保存并开始分析」

      配置存在你的浏览器里，不会上传。之后每次点深读直接出结果。

      💾 数据备份与迁移

      • 💾 备份 JSON：下载全部数据，建议每周一次
      • 📝 导出 Markdown：导出为 .md 文件，存到笔记软件
      • 📂 导入 JSON：换设备时，旧设备导出 → 新设备导入

      🔒 隐私说明

      • 所有数据存在你的浏览器 localStorage 中
      • 不同人、不同设备完全隔离，互相看不到
      • AI 分析通过加密通道发送给 DeepSeek，仅用于分析
      • 清除浏览器缓存会删除数据，请定期备份

      ⏰ 日常节奏

      每天睡前填今日复盘 + 明日计划（5分钟）
      每周日晚周复盘 → AI 高我深读（10分钟）
      每月最后一天月复盘 → AI 高我深读（20分钟）
      每周备份一次 JSON（10秒）

      "为学日益，为道日损。"
