# 🌙 暮省 · 使用指南

> 每日 5 分钟，睡前复盘，照见自己。

---

## 这是什么？

「暮省」是一个每日复盘工具。名字取自"暮而省"——晚间反省。

特点：
- **隐私第一**：你的所有数据存在自己浏览器里，不上传任何服务器，别人看不到
- **零门槛**：打开网页就能用，不用注册，不用安装
- **AI 高我深读**：用东方哲学视角深度分析你的复盘数据

---

## 快速开始（3 步）

### 1. 填写今日复盘

打开暮省，默认就是「✍️ 今日复盘」页面：

- **今日完成**：会自动带过来昨天「明日计划」里的事项，完成的打勾 ✓，也可以手动添加
- **今日心情**：选一个 emoji
- **亮点 / 困难 / 学习**：简单写几句
- **反思**：如果重来会怎么做（必填）
- **效率评分 / 休息评分**：点星星打分，1-5 颗星

填完点 **💾 保存今日**。

### 2. 写明日计划

切到「☀️ 明日计划」：

- **核心 3 件事**：明天最重要的 3 件事
- **其他待办**：可以添加多条
- **提醒**：注意事项

保存后，明天打开暮省时这些会自动出现在「今日完成」里。

### 3. 修行反思（选填）

切到「🧘 修行反思」：

- 随机一句道德经/庄子/禅宗语录
- 写下今天的感悟、困惑、念头观察
- 可以一键复制或导出

---

## 周复盘 & 月复盘

切到「📅 历史记录」，每条记录右边有两个按钮：

### 📊 周复盘

点击后自动生成报告：
- **数据摘要**：平均效率、休息、任务完成率
- **趋势图**：每天的效率和休息柱状图
- **心情分布**：本周情绪概览
- **智能分析**：自动识别效率趋势、情绪模式、重复困难等
- **🧠 AI 高我深读**：点击后 AI 以"高我"视角深度分析，回答七个核心问题

### 📈 月复盘

同样生成报告，AI 深读会从八大维度分析：
- 时间感知、情绪觉察力、念头模式、执着点
- 行动对齐、成长弧线、人际关系、身体能量

---

## AI 高我深读配置（首次使用）

第一次点「🧠 AI 高我深读」时需要配置：

| 配置项 | 填什么 |
|--------|--------|
| Base URL | `https://api.deepseek.com` |
| API Key | （向暮省创建者获取） |
| 模型 | `deepseek-v4-flash` |

配置保存在你自己的浏览器里，不会上传。之后每次点深读直接出结果，无需再配。

> 如果你用自己的 DeepSeek API Key，注册 [platform.deepseek.com](https://platform.deepseek.com)，充值 10 元可用约 1600 次。

## 数据备份与迁移

### 备份

「历史记录」页顶部 → **💾 备份 JSON** → 下载备份文件

建议每周备份一次，暮省会自动提醒你。

### 导出 Markdown

**📝 导出 Markdown** → 导出全部记录为 `.md` 文件，可以存到笔记软件里归档。

### 换设备 / 换浏览器

1. 旧设备：💾 备份 JSON
2. 新设备：打开暮省 → 📂 导入 JSON
3. 如果有日期冲突，会问你是覆盖还是跳过

## 日常使用节奏

| 时间 | 动作 | 耗时 |
|------|------|------|
| 每天睡前 | 填今日复盘 + 明日计划 | 5 分钟 |

## 隐私说明

- 🔒 你的所有数据保存在你自己的浏览器 localStorage 中
- 不同人、不同设备的数据完全隔离，互相看不到
- AI 分析通过加密通道发送给 DeepSeek，仅用于分析，不会被存储
- 清除浏览器缓存会删除数据，请定期备份

---

## 常见问题

**Q：数据会丢吗？**
A：只要不清浏览器缓存就不会丢。建议每周备份一次 JSON。

**Q：手机能用吗？**
A：能，暮省是响应式设计，手机浏览器打开就行。

**Q：AI 高我深读失败怎么办？**
A：检查 API Key 是否正确、账户是否有余额。错误提示会告诉你具体原因。

**Q：朋友能看到我的复盘吗？**
A：看不到。每个人的数据在自己浏览器里，完全隔离。
